Connection settings

Saved connection

Address and ID are saved on Connect. Optionally encrypt the token with a password; the password is never saved. Upgrade in place; uninstall may remove plugin data.

Basic chat beta boundaries

No automatic downgrade or reconnect after restart. Optional password-encrypted token storage. Self-hosted servers remain restricted by the manifest allowlist.

Current protocol is tested offline, not Cloud-proven. Legacy v0.1.7 cannot register Pi and is disabled. Once locally allowed: session inventory, create/send/interrupt, and final response status sync. Remote tool approval and fine-grained streaming are not supported; local tool permissions may wait for approval locally.
