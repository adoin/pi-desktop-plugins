Capabilities and limits

Current protocol is tested offline, not Cloud-proven. Legacy is disabled. Remote tool approval and fine-grained streaming are not supported; local permissions still apply.

Connection settings

Saved connection

Address and ID are saved on Connect. Optionally encrypt the token with a password; the password is never saved. Upgrade in place; uninstall may remove plugin data.

Sharing scope

Load local saved projects, then select up to 32. On Connect, with sharing consent, paths, titles and conversation text are uploaded. Empty projects appear remotely only after a real session exists. New projects are not automatically selected. Changes apply only on reconnect; Disconnect to revoke immediately.

Changes take effect only when you connect again. Disconnect to revoke immediately.

Connection safety

Requires PI-Desktop 0.18.0+. Approve net.anyHost when installing/updating; it is an arbitrary-host grant, not a per-domain prompt. Enter a trusted direct HTTPS origin without /api/v2 or proxy subpaths. Authentication and uploads refuse redirects; TLS checks remain enabled. No automatic connection after restart.

Connection events

Only recognized event codes and bounded diagnostic details are shown; credentials are excluded.
